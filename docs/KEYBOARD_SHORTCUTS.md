# Keyboard Shortcuts Reference

> **macOS users**: Use `Cmd` in place of `Ctrl`.

---

## File Operations

| Shortcut | Action |
|---|---|
| `Ctrl + N` | 📝 New File |
| `Ctrl + O` | 📁 Open Folder |
| `Ctrl + S` | 💾 Save File |

---

## Navigation

| Shortcut | Action |
|---|---|
| `Ctrl + P` | 🔍 Quick Open — fast file switcher |
| `Ctrl + Shift + P` | ⚡ Command Palette — search & run any command |
| `Ctrl + G` | 📍 Go to Line |
| `Ctrl + Shift + O` | 🧭 Go to Symbol (functions, structs, macros) |
| `Ctrl + Shift + F` | 🔎 Search & Replace in Files |

---

## Editor — Commenting

| Shortcut | Action |
|---|---|
| `Ctrl + /` | Toggle Line Comment (`//`) |
| `Shift + Alt + A` | Toggle Block Comment (`/* */`) |

---

## Editor — Line Operations

| Shortcut | Action |
|---|---|
| `Alt + Up` | ↑ Move Line Up |
| `Alt + Down` | ↓ Move Line Down |
| `Shift + Alt + Down` | 📋 Duplicate Line Below |

---

## Editor — Selection & Find

| Shortcut | Action |
|---|---|
| `Ctrl + F` | Find in File |
| `Ctrl + H` | Find & Replace in File |
| `Ctrl + D` | Select Next Occurrence |

---

## Bookmarks

| Shortcut | Action |
|---|---|
| `Ctrl + F2` | 🔖 Toggle Line Bookmark |
| `F2` | 🔖 Jump to Next Bookmark |

---

## Build & Run

| Shortcut | Action |
|---|---|
| `Ctrl + Enter` | ▶ Run Code (compile & execute) |
| `Ctrl + Shift + B` | 🔨 Build Only (no execute) |

---

## Tools

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + S` | 📸 Code Snapshot |
| `Ctrl + Alt + R` | 📄 Generate Lab Report |
| `Ctrl + ,` | ⚙️ Preferences / Settings |

---

## Terminal

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + C` | 📋 Copy terminal selection |
| `Ctrl + Shift + V` | 📋 Paste to terminal |

---

## Command Palette Actions

These actions can be invoked from the Command Palette (`Ctrl + Shift + P`):

| Command | Description |
|---|---|
| `▶ Run Code` | Compile and execute the current file |
| `🔨 Build Only` | Compile without running |
| `✨ Format Code` | Format with clang-format (`Ctrl + Shift + Alt + F`) |
| `💾 Save File` | Save the active file |
| `📝 New File` | Create a new untitled file |
| `📁 Open Folder` | Open a project directory |
| `📄 Open File` | Open a single file |
| `📸 Code Snapshot` | Export code as a styled screenshot |
| `📄 Lab Report` | Generate academic lab report |
| `⚙️ Preferences` | Open settings modal |
| `💬 Toggle Line Comment` | Comment/uncomment current line |
| `💬 Toggle Block Comment` | Wrap selection in block comment |
| `🔍 Search & Replace in Workspace` | Search across all files |
| `🧹 Clean Build Artifacts` | Delete compiled binaries |
| `🔄 Rebuild Workspace` | Full rebuild |
| `🔖 Toggle Line Bookmark` | Bookmark/unbookmark current line |
| `🔖 Jump to Next Bookmark` | Navigate to next bookmarked line |
