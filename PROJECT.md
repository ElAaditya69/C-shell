# C-Shell

## Mission

Build the best beginner-friendly IDE for learning C programming while
remaining useful for professionals.

## Vision

-   Native desktop app (Tauri + Rust + React)
-   Fast compile/run
-   Learning mode
-   Automatic code/output screenshots
-   Automatic lab report generation
-   Open source

## Tech Stack

-   React
-   TypeScript
-   Tauri v2
-   Rust
-   GCC/Clang
